# Security Policy

## Responsible Disclosure

Security research documented in this repository is intended for responsible disclosure and educational purposes.

Findings are reported to the affected organization whenever possible before public disclosure.

## Sensitive Information

The following information must not be published:

- Passwords
- API keys
- Access tokens
- Refresh tokens
- Session cookies
- OAuth client secrets
- Device codes
- Registration tokens
- Private keys
- Database credentials
- Personal information
